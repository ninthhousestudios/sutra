# Handoff — sutra

## What just shipped

Five code intelligence features landed in 2 commits on `main`:

- **Complexity metrics** — cyclomatic + cognitive per function/method (Rust + Dart), stored in DB, surfaced in `sutra_outline` and `sutra_map`
- **Dead code detection** — `sutra_dead` tool finds zero-ref symbols and zero-importer files
- **Hotspot ranking** — `sutra_hotspots` ranks files by churn × blast_radius × complexity
- **File health scores** — `sutra_file_health` gives 0–100 maintainability index per file
- **Audit verdicts** — `sutra_diff_impact` now returns pass/warn/fail with reasons

All 135 tests pass. Binary installed.
